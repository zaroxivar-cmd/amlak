پشتیبان‌گیری

اطلاعات (فایل‌ها و مخاطبین) روی همین مرورگر گوشی ذخیره می‌شود. گاهی پشتیبان بگیرید، مخصوصاً قبل از پاک‌کردن اطلاعات مرورگر.

همگام‌سازی با GitHub
اطلاعات در یک repository خصوصی خودت ذخیره می‌شود. توکن فقط روی همین گوشی می‌ماند و در پشتیبان‌گیری معمولی نمی‌آید.
پیشرفته: جایگزینی کاملاگر مشکلی پیش آمد: «ارسال» نسخه این دستگاه را روی GitHub می‌گذارد و «دریافت» نسخه GitHub را جایگزین این دستگاه می‌کند.
راهنمای ساخت توکن ۱) در GitHub یک repository خصوصی (Private) بساز، مثلاً amlak-data. این را جدا از repository سایت بساز.
۲) Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
۳) در Repository access گزینه Only select repositories را بزن و فقط همان repository را انتخاب کن.
۴) در Permissions ← Repository permissions، گزینه Contents را روی Read and write بگذار.
۵) توکن را کپی کن و بالا بچسبان. روی گوشی دیگر هم همین کار را بکن و «دریافت از GitHub» را بزن.
تماس تمام شد. اگر لازم است نام این شماره را ثبت یا ویرایش کنید.
